# CNN from Scratch

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![NumPy](https://img.shields.io/badge/NumPy-1.21+-yellow.svg)](https://numpy.org/)

A hands-on implementation of a Convolutional Neural Network (CNN) from scratch using only NumPy. Demonstrates core concepts: convolution, pooling, backpropagation, and training on MNIST dataset. No TensorFlow/PyTorch dependencies.

**Built today (Feb 27, 2026) by Harshini V as a deep learning exercise.**

## 🚀 Features
- 2D Convolution with customizable kernels (e.g., 3x3, stride=1).
- Max/Avg Pooling layers.
- ReLU, Sigmoid activations with derivatives.
- Fully connected layers and softmax output.
- Cross-Entropy loss and SGD optimizer.
- Forward/backward passes with manual gradients.
- Training visualization (loss/accuracy plots via Matplotlib).

Achieves ~92% accuracy on MNIST test set after 10 epochs.

## 🛠 Tech Stack
- **Core**: Python 3.x, NumPy (matrix ops)
- **Viz**: Matplotlib (plots)
- **Notebook**: Jupyter (`cnn-from-scratch.ipynb`)
